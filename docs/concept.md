# 構想 v2 — onomato-atlas(音象アトラス)

**近代日本語のオノマトペについて、音韻素性と用法分布が一致するかを測り、一致した分だけを地図にする**
静的 Web アプリ。辞書引きアプリにはしない。

v1(元の会話ベース)からの改訂。改訂の根拠はすべて §2 の事前実測にある。
v1 は `onomato-atlas-concept-v1.md` に保存。

## 1. 主張(この一文が検証対象)

> **語の音の形は、その語がどんな文脈に出るかを予測する。**

音側(表記から決定論的に得る素性)と意味側(青空文庫での共起分布)を**別々に測り**、
両者が揃うかを見る。揃えば音象徴が見えている。揃わなければ、揃わないと表示する。

v1 では座標を `f(音韻素性)` と定義していたため、
「形態バリアントは持続軸だけ動く」「濁音は重い方へ動く」は**構成上の恒真式**であり、
何も反証できなかった。二チャネル化はこの欠陥の修正である。

**体験の核**: 意味空間に語を配置し、音素性で色分けする。色が領域を作れば音象徴が目に見える。

## 2. 事前実測(2026-08-25)

kokoro-graph の青空文庫 bronze を用い、SPEC を書く前に机上の仮定を数で置き換えた。
標本は probe により 100〜317 作品(3.7M〜13.1M 字)。

### 実測 1 — 語彙規模の天井(317 作品 / 13,054,219 字)

ABAB 型 異なり **774 語** / 延べ 15,905。頻度別: ≥3 → 479 / ≥10 → 272 /
**≥30 → 119** / ≥100 → 23 / ≥300 → 6。
v1 の「300 語」は語釈を書く語数としては妥当だが、統計的に扱える語数としては楽観的だった。

### 実測 2 — 語境界は必須(偽陽性 10.4%)

正規表現のみ 519 語/5,310 件 → 形態素境界一致 386 語/4,759 件。**延べの 10.4% が偽陽性**。
消滅例: `いていて`(48→0、「置いていて」由来)、`のものも`(18→0)、`らはらは`(「彼らはらはらと」由来)。
変化形はさらに深刻で、境界なしだと `からん`=291(「わからん」「つまらん」)、
`にやっ`=274(「…にやって」)、`うやっ`=180 を拾う。**正規表現のみの抽出は使い物にならない。**

### 実測 3 — 品詞は散らない(v1 §8-1 の予想は外れ)

ABAB トークンの品詞分布: **副詞 90.6% / 形状詞 5.3% / 名詞 2.5% / 感動詞 1.3% / その他 0.3%**。
「解析器がオノマトペを散らす」は誤りで、副詞+形状詞+感動詞で 97.2%。POS フィルタはクリーン。

### 実測 4 — しかし品詞でも頻度でも擬態語は切り出せない

語境界一致の上位 20 語のうち、**半数以上が擬態語でない反復副詞**
(とうとう 371・なかなか 273・わざわざ 264・いよいよ 264・だんだん 260・いろいろ 241・
ますます・しばしば・たびたび・もともと)。しかも**すべて副詞 100%**。

→ **語彙リストは「コーパス抽出 → 人手 curation」の二段が必須**(§4)。
v1 §0 の変更 3(コーパスから自前生成)は権利面では正しいが、「自動で clean な語彙が出る」は誤り。

### 実測 5 — オラクル対の収量

- **形態パラダイム**: 語幹頻度 ≥3 の 479 件中、2 形態以上 392 件 / 3 形態以上 297 件 / 4 形態以上 182 件。
  ただし境界なし計測なので実測 2 の偽陽性を含む。**境界フィルタ後の再測定が L1 の必須項目**。
  良好例: `がさ`(がさがさ/がさっと/がさっ/がさり/がさん/がさーっ)、`じろ`(じろじろ 71/じろり 72)、
  `ばた`(ばたばた 88/ばたり 27/ばたん 9)
- **濁音ミニマルペア**: 94 組、**両側とも頻度 ≥5 が 30 組**。
  良好: きらきら(72)/ぎらぎら(37)、さらさら(72)/ざらざら(32)、からから(37)/がらがら(45)、
  ころころ(25)/ごろごろ(53)、するする(50)/ずるずる(44)、くるくる(75)/ぐるぐる(126)
  ノイズ混入: たんたん(1)/だんだん(842)、わさわさ(2)/わざわざ(435)、ますます(295)/まずまず(2)
  → curation 後で **20〜25 組**が実用と見込む

### 実測 6 — 意味側チャネルは窓共起で取れる(200 作品 / 8,867,363 字・シード 40 語 / 延べ 2,020)

直後の形態素: **`と`(606) / `し`(318) / `する`(73) / `に`(40)**。
後方窓で最初の用言までの距離: 1 形態素 48.3% / 2 形態素 19.6% / 3 形態素 9.2% /
4〜5 形態素 13.7% / 到達せず 9.2%。**窓 3 以内で 77.1% が用言に到達**。

→ **係り受け解析器は不要。窓共起で足りる**(ビルド依存を fugashi のみに保てる)。

### 実測 7 — 軽動詞ストップリストが決定的

係り先用言をそのまま取ると軽動詞が支配する(きらきら:為る 16 / そわそわ:為る 30 /
ざらざら:為る 13 / ばたばた:為る 11)。除くと信号は一気にクリーンになる:

```
きらきら → 光る(14) きらめく(4) 輝く(3)
ぐるぐる → 回る(30) 巻く(10) 巻き付ける(9) 回す(6)
ばたばた → 駆ける(4) 動かす(2) 出る(2)
ざらざら → 当たる 撫でる 潜る 零れる
```

意味ベクトル密度(窓±5 の内容語): 異なり共起語の**中央値 120.5・最小 19**。
上位語は 150〜305。**最小 19 は薄すぎる** → 頻度下限とコーパス拡大が必要(実測 1・§3)。

## 3. 二チャネル設計

### 音側 — 決定論(人手ゼロ・全語にスケール)

表記から機械的に取れる。**主張ではなく観測**なので検証不要。

- 語頭子音・第 2 子音・母音列
- 形態型: ABAB / ABっと / ABっ / ABり / ABん / ABーっ
- 濁音・半濁音・促音・撥音・長音の有無

### 意味側 — コーパス分布(独立チャネル)

- **特徴 A 係り先用言**: 後方窓 5 で最初の動詞/形容詞、**軽動詞ストップリスト適用**。強い信号(実測 7)
- **特徴 B 窓共起**: 窓 ±5 の内容語(動詞・形容詞・名詞・形状詞・副詞)、lemma 単位
- PPMI 重み付け → SVD で低次元化。次元数は較正で決める(先に書かない)

> **軽動詞ストップリストは測定器の設計であり、研究の一部**。
> yamato-gaze のスタンス辞書と同じ規律を適用する:
> ヘッダに version を持ち、変更は専用コミット(`data: stoplist vX.Y — 理由`)、
> 変更したループでは**感度分析**(変更前後の座標変位)を実行しループログに記録する。

### 主張 = アラインメント

音側の構造から意味側の位置をどれだけ予測できるか。5 軸(硬⇔柔/軽⇔重/瞬間⇔持続/乾⇔湿/快⇔不快)は
**意味空間への事後解釈のオーバーレイ**であって、座標の定義ではない。

## 4. 語彙 curation(実測 4 の帰結)

完全自動化はできないので、二段で明文化する。

1. **抽出(自動)**: 形態素境界 + POS(副詞/形状詞/感動詞) + 頻度下限 → 候補語
2. **選別(人手承認)**: 判定基準を SPEC に明文化する。
   - 採用: 音・声・様態を模す語(きらきら・ばたばた・そわそわ)
   - 除外: 反復による強調・程度の副詞で模写性のない語(とうとう・なかなか・わざわざ・いよいよ・もともと)
   - 判断がつかない語は `needs_review` に出力し、**エージェントが独断で採否を決めない**
     (yamato-gaze の実体辞書規律を踏襲)
3. 全採否判断を `vocab_manifest.json` に理由付きで記録(kokoro-graph の corpus_manifest 方式)

## 5. オラクル(二チャネル版・すべて非自明)

| ID | 内容 | 収量見込み |
|---|---|---|
| **O-1'** | 形態パラダイム(ころころ/ころっと/ころり/ころん)の**分布的**差分が、パラダイム横断で一貫した方向を向くか | 境界フィルタ後に再測定(実測 5) |

## 8. 権利・名乗り

- 語釈・素性定義・5 軸定義・ストップリストは**すべて自前**。既存の擬音語辞典から語釈を持ち込まない
- 語彙リストもコーパス実測 + 自前 curation。辞典の見出し語リストに依存しない
- 青空文庫本文は PD。**底本・入力者・校正者の表記を引用に必ず付す**。
  引用は yamato-gaze の**二層原則**(表示層は逐語一致 / 分析層は正規化済み)を踏襲
- ライセンス二層: コード MIT / 自作データ CC BY 4.0
- **名乗りは「近代日本語のオノマトペ」**。青空文庫は明治〜昭和前期であり、現代の語感とはずれる
  (kokoro-graph の擬古文問題と同型)。年代分布を UI に明示し、現代語への一般化を主張しない

## 9. 残る未決

1. **頻度下限をいくつにするか** — 意味ベクトルの安定性で決まる。L1 のコーパス拡大後に実測(現行 8.9M 字で異なり共起語 中央値 120.5・最小 19)
2. **O-1' が破れた場合** — 音側と意味側が揃わない。これは**否定的結果として公開する**。ただし L4 の UI 設計は「揃わない」前提に組み直しになる
3. **5 軸が事後解釈できなかった場合** — SVD 次元に人間可読な意味が乗らない可能性。その場合 5 軸スライダー UI は成立しない。L3 の結果で L4 の UI を確定する
4. **語釈 300 語の執筆コスト** — 自前定義が必須なので削れない。ただし v0.1 では**用例で語釈に代える**方針も選べる(実測の用例のほうが権利的にも実測主義的にも強い)
5. **母音 e の「非規範的」仮説**(へなへな・でれでれ)— 対称対が作れず検証できない。**検証できないなら UI で主張しない**

# 11. 先行検証レポート(2026-08-25)— 二チャネル設計の実地検証

**目的**: SPEC を書く前に §9 未決 3(SVD 次元が事後解釈できるか)を潰す。
**結論**: **二チャネル設計は機能する。O-1' は通った。ただし 5 軸スライダー UI は成立しない。**

## 手順

kokoro-graph bronze 317 作品 / 13,053,903 字。fugashi + unidic-lite。

1. 形態素境界 + POS(副詞/形状詞/感動詞/名詞) + 頻度 ≥5 で候補抽出 → **752 語**
2. **表記ゆれ統合**(カタカナ → ひらがな。きらきら/キラキラ) → **606 語**。これは必須処理で、
   統合しないと同一語が二重計上され頻度が半減する
3. 暫定 curation(非擬態語 67 語を除外)+ 頻度 ≥10 → ABAB **201 語**
4. **変化形の自動 curation 規則を発見**(下記)→ 変化形 65 語を追加 → **語彙 266 語**
5. 窓 ±5 の内容語(軽動詞ストップリスト適用)で共起行列 266 × 1,291 → PPMI → SVD 30 次元

## 発見 A — 変化形の自動 curation 規則

`ABり` を素朴に取ると **`ひとり` `つもり` `つまり` `かなり` `やはり` `まわり` `あたり` `しきり` `ふたり` `ほとり`**
が大量に混入し、SVD の第 1 次元がこのノイズで占められた(実際に起きた)。

**規則: 変化形は「語幹が ABAB 型として語彙内に独立に存在する」ことを要件とする。**

これだけで 65 語すべてがクリーンになった(`どたり くすり ぽかり だらり うねり ちらり どろり ひらり
きらり かたり じろり きりり ひやり にやり ぞろり くるり ごろり がらり ぶらり はらり ぐるり…` — 偽陽性ゼロ)。
人手 curation が必要なのは **ABAB 型だけ**で済む。これは L1 の工数を大きく下げる。

## 発見 B — 意味側チャネルは明確に信号を持つ

最近傍(コサイン類似・音韻素性を一切使っていない):

```
きらきら → ぎらぎら(.84) ちかちか(.76) きらり(.69) てらてら(.68) つやつや(.66)   ← すべて「光」
ぐるぐる → くるくる(.90) ぐるっ(.67) ぐるり(.52) ころころ(.52)                    ← すべて「回転」
そわそわ → はきはき(.79) おずおず(.78) おどおど(.75) もじもじ(.74)              ← すべて「態度」
どきどき → むかむか(.84) わくわく(.82) ひやひや(.73) はあはあ(.71)              ← すべて「身体感覚」
ばたばた → ぱたぱた(.87) はたはた(.72) どたどた(.62)                            ← すべて「音・動作」
```

## 発見 C — **O-1' は通った(強い有意)**

ABAB → ABり の 47 対で、分布差分ベクトルの方向一致を leave-one-out 検定:

| 条件 | 同方向率 | 平均 cos | 平均差分長 |
|---|---|---|---|
| **実測** | **41/47 (87%)** | **+0.192** | **0.266** |
| 対照 1(頻度比マッチ無関係対) | 58% ± 9% | +0.037 ± 0.036 | 0.164 ± 0.020 |
| 対照 2(対応シャッフル・頻度分布完全保存) | 76% ± 4% | +0.132 ± 0.006 | 0.223 ± 0.004 |

片側二項 p = **8.9 × 10⁻⁸**。対照 1 に対し z = +3.36 / +4.29 / +5.12、
より厳しい対照 2 に対しても z = +2.86 / +9.25 / +9.84。

**対照 2 が 76% と高いことの意味**: 効果の大半は「`ABり` という形態そのものが持つ共通方向」であり、
語ごとの対応分はその上乗せ。両方とも実在するが、**強いのは形態の共通効果のほう**。
この内訳は正直に SPEC に書く。

**方向は解釈可能**:
- **+極**: さらり ころり ばたり すべり べたり するり がぶり すらり(すべて ABり = 一回完了)
- **−極**: ぷりぷり ぞろぞろ ことこと のろのろ ごとごと うようよ ぴくぴく(すべて ABAB = 反復継続)

**構想が予測した「瞬間⇔持続」軸が、音韻素性を一切入力せずに、コーパス分布だけから再発見された。**
v1 の恒真式問題は解消している。

**汎化も確認**: ABAB → ABん(n=12)は 8/12 が同方向で、かつ**「り」方向との一致 11/12**。
`ざらん ごとん ぽかん どきん ばたん がらん どろん ぽつん どしん` — 別の形態が同じ意味方向を向いている。

## 発見 D — **O-2' は 317 作品では検出できない(否定的結果)**

意味的に対応する濁音ペア 12 組に絞っても:

| | 同方向率 | 平均 cos | p |
|---|---|---|---|
| 濁音ペア 12 組(人手選別) | 7/12 (58%) | +0.087 | 0.387 |
| 濁音ペア 17 組(自動) | 12/17 (71%) | +0.094 | 0.072 |

## 発見 E — **5 軸スライダー UI は成立しない(§9 未決 3 の回答)**

SVD 次元が捉えるのは**感覚モダリティと場面**であって、質感の形容詞的次元ではない:

- d2: そわそわ ぐずぐず もじもじ こそこそ(心的・対人) ⇔ きらきら ひらひら さらさら(視覚・物理)
- d3: ばたばた ぱたぱた がらがら とんとん(**音**) ⇔ きらきら ぎらぎら(**光**)
- d4: どんどん じめじめ ぞろぞろ だらだら(場・持続) ⇔ ぐるり くるり じろり(瞬間・回転)
- d5: さらさら ぽたぽた かちかち ぱらぱら(離散) ⇔ ぞろぞろ ゆらゆら きらきら(連続)

寄与率は低い(d1 5.0% / d1-5 累積 9.2% / d1-30 累積 27.2%)。行列が疎(非零率 3.5%)なため、
**低次元射影より 30 次元コサイン近傍のほうが遥かに信頼できる**。

「硬⇔柔 / 軽⇔重 / 乾⇔湿 / 快⇔不快」は SVD 主成分としては現れなかった。

## 発見 F — 軸は主成分ではなく「対比ベクトル」として取り出す(UI 設計の確定)

これが本検証の最大の設計的収穫。

**瞬間⇔持続軸は SVD の主成分には現れないが、対比ベクトル(ABAB→ABり の平均差分方向)としては
明確に存在し、検定も通っている。** 全語をこの方向に射影すれば、**検証済みの軸スコア**が全語に付く。

→ **UI の確定方針**:
1. **地図**: 30 次元コサイン近傍から作る意味マップ(感覚モダリティが領域として現れる)
2. **軸**: 手で定義した 5 軸スライダーではなく、**コーパスから推定した対比ベクトルのうち、
   検定を通ったものだけ**を軸として提供する
   - 瞬間⇔持続軸 = ABAB↔ABり/ABん 対比(**採用**・p=8.9e-08)
   - 重さ/粗さ軸 = 清音↔濁音 対比(**現時点では不採用**・p=0.39。コーパス拡大後に再判定)
3. 音素性は地図の**色分け**として重ねる(領域を作るか否かが見どころ)

**較正ファーストの原則が UI レベルまで貫かれる**: 検定を通っていない軸はスライダーを出さない。
